# Attribution

## Original content

All content in Waddle Wars is original work created for this project:

- **Code**: all GDScript, Python tooling, and configuration — original.
- **3D art**: every model is procedural (Godot primitive meshes + SurfaceTool
  geometry composed in code). No imported models.
- **2D art**: `assets/icons/icon.svg` (logo/icon) — original SVG drawn for this
  project. UI is built from Godot Control nodes and code-generated styles.
- **Audio**: every sound effect and music track is synthesized by
  `tools/generate_audio.py` (original DSP code, original melodies). No samples,
  no recordings, no third-party audio.
- **Fonts**: the project uses Godot's built-in default font only; no font files
  are bundled.

No copyrighted, licensed, or third-party assets are included. The game does not
imitate any existing franchise's characters, names, logos, or melodies.
