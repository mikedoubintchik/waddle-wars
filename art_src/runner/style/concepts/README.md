# Runner concepts

Concept images guide composition, shape language, palette, lighting, and asset
briefs. They are not runtime art and remain below `art_src/.gdignore`.

## `runner_day_keyart_v1`

Useful direction:

- Clear near/mid/far research-port staging.
- Broad destination horizon and strong vanishing point.
- Cyan route, white snow frame, navy forms, warm hardware.
- Gold collect, orange dodge, and green launch cues.
- Rounded authored geometry and readable landmark rhythm.

Production cautions:

- Portrait poster framing is not gameplay camera framing.
- Penguin clothing, face, anatomy, and gear are concept-only. Build original
  species-compatible forms around existing Waddle Wars cosmetics.
- Do not trace domes, observatory, crane, hazard, collectibles, or lane layout.
  Re-author each object from game requirements and style bible.
- Image contains visual ideas, not texture/model source.

Exact prompt and provenance live beside image. Runtime manifest intentionally
does not register it.
