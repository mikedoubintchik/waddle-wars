## Semantic and implementation notes

- Fish icon represents currency only. Leaderboard ranking values use star/score symbol; corrected concept saved.
- Runner-only MVP: do not expose Race or unsupported modes from these menus.
- The Shop image is conceptual. It must not imply a purchase or real price until store products and fulfillment are operational.
- Account image shows guest state only; signed-in and error states need separate live UI.
- Credits image contains placeholder bars, not actual people or license text.
- Generate separated clean background and icon assets before integration; build buttons, labels and scrolling with real UI nodes.
